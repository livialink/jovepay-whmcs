# Changelog

## 1.0.0

- Initial public release of the JOVEpay crypto payment gateway for WHMCS 8.x
- Third-party redirect checkout to the JOVEpay hosted payment widget
- Hosted payment widget with light and dark themes and configurable locale
- Configurable Pay Now button label
- Branded invoice payment button with JOVEpay logo and overlapping crypto coin icons
- HMAC-signed Instant Payment Notifications (IPN) via `X-JOVEPAY-SIG`
- Automatic invoice payment recording with partial payment support
- Duplicate transaction protection through WHMCS callback validation
- Optional testnet mode for safe end-to-end testing
- Marketplace / Apps & Integrations readiness: `whmcs.json`, `logo.svg`, LICENSE, README, CHANGELOG, and marketing description
- Admin UsageNotes with account signup guidance
- Callback hardening aligned with WHMCS sample gateway helpers
